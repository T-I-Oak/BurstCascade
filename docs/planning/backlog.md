# Burst Cascade 開発バックログ
バックログの追加はプロダクトオーナーの指示に従うこと。

## 次回改版時に対応するバックログ
- [ ] 共通ライブラリの新しいチュートリアル仕様へ移行する
    - 従来仕様は互換として残っているが非推奨のため、次回改版時に新仕様へ移行する。
    - 既存のチュートリアル表示・進行・保存データが新仕様で正しく動作することを確認する。
- [ ] 共通ライブラリの読み込み方式を GravityFreight 型に合わせる
    - リリース済みゲームでは、共通ライブラリを実行時の動的URL importではなく、ビルド時に静的に取り込む方式を標準とする。
    - BurstCascade では即時対応せず、次のいずれかの場合に対応する。
        - 共通ライブラリで破壊的な仕様変更が発生する場合。可能であれば、共通ライブラリ変更前に対応する。
        - BurstCascade 側で次回の改版作業が発生する場合。
